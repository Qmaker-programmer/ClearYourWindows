## 🧹 Clear Your Windows - Ultimate Edition 🚀
Clear Your Windows es un script interactivo desarrollado en Batch y PowerShell diseñado específicamente para programadores y usuarios avanzados que buscan exprimir al máximo el rendimiento de su PC con Windows 10 u 11.

Esta herramienta elimina el bloatware (basura preinstalada), optimiza el consumo de RAM/CPU y configura automáticamente un entorno de desarrollo profesional en minutos.

# 📋 Características Principales
*🗑️ Limpieza de Sistema*
E**liminación de Bloatware: Borra apps como El Tiempo, Noticias, Mapas, Correo y más.**

* **Adiós Juegos: Elimina Solitario, Candy Crush y servicios de Xbox.**

* **Componentes Obsoletos: Desinstala el Visor XPS y desactiva Cortana de raíz.**

* **Desinstalación de Edge & OneDrive: Libera recursos eliminando integraciones forzadas.**

# ⚡ Optimización Extrema
* **Privacidad Total:** Desactiva la telemetría, el rastreo de datos y la publicidad de Windows.
* **Rendimiento Visual:** Ajusta efectos visuales para priorizar la velocidad.
* **Gestión de Memoria:** Optimiza el archivo de paginación (VRAM) según tu RAM física.
* **Control de Updates:** Pausa las actualizaciones automáticas para que no interrumpan tus compilaciones.

# 💻 Entorno para Programadores (Dev Mode)
**Visibilidad: Muestra extensiones de archivos y archivos ocultos automáticamente.**

Instalación Automatizada (via Winget):

* Git
* Visual Studio Code
* Python 3.12
* Node.js
* **Terminal Pro: Instala y configura la fuente Cascadia Code.**
* **Linux en Windows: Habilita WSL2 con un solo comando.**

# 🚀 Cómo usarlo
**Descarga el archivo [src/CYW.bat](https://raw.githubusercontent.com/Qmaker-programmer/ClearYourWindows/refs/heads/main/src/CYW.bat)**

**Ejecuta como Administrador: Haz clic derecho sobre el archivo y selecciona "Ejecutar como administrador" (esto es vital para modificar el Registro y servicios).**
**Elige tu camino:**
* **Usa las opciones individuales (1-26) para un control total.**
* **Usa la opción [29] SUPER ULTRA MEGA TODO para una transformación automática y completa.**
* **Reinicia: Al terminar, reinicia tu PC para que todos los cambios en el kernel y servicios surtan efecto(solo para algunos)**

# ⚠️ Advertencias y Seguridad
* **Punto de Restauración: El script incluye una opción para crear un punto de restauración. Úsalo siempre antes de realizar cambios masivos.**

* **Microsoft Edge: Eliminarlo puede afectar ciertas funciones web menores del sistema (como la previsualización de archivos en algunos visores).**

***Nota: Uso bajo propia responsabilidad: Este script realiza cambios profundos en el Registro de Windows.***
